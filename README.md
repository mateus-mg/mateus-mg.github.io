# Mateus Marques Portfolio

Personal portfolio site built with HTML, CSS, and JavaScript. Hosted on GitHub Pages.

**URL:** https://mateus-mg.github.io

## Features

- Modern, responsive design with Inter font
- Dynamic GitHub repository loading
- Smooth animations and hover effects
- Professional color palette
- Experience, Education, Tech Stack and Projects sections

## Development

This site is automatically deployed to GitHub Pages when changes are merged into the `main` branch.

## Structure

```
.
├── index.html              # Main page
├── css/
│   └── style.css           # Stylesheet
├── js/
│   └── main.js             # Repository loader
├── data/
│   └── repos.json          # Generated repository data
├── scripts/
│   └── fetch_repos.py      # GitHub API fetcher
└── .github/workflows/
    ├── deploy-pages.yml    # GitHub Pages deployment
    └── update-repos.yml    # Repository data updater
```
